# 💻 FPGA Real-Time Embedded System — DE10-Lite

## Overview

An embedded real-time project built on the **DE10-Lite FPGA board** using a Nios II soft-core processor.

The system combines FPGA hardware design with interrupt-driven C software.

## Software & Technologies

- DE10-Lite
- Intel Quartus Prime
- Platform Designer / Qsys
- Nios II
- C
- On-Chip Memory
- PIO / GPIO
- JTAG UART
- Hardware Timers
- Interrupts

## Technical Areas

- FPGA system integration
- Embedded C
- Timer management
- Interrupt handling
- GPIO
- Alarm functions
- 12h / 24h modes
- Snooze behavior
