# 🗺️ TurtleBot3 Autonomous Navigation

## Overview

A ROS 2 robotics project focused on reprogramming and configuring a **TurtleBot3** for indoor mapping and autonomous navigation.

The robot generated maps of indoor environments, navigated between target positions and reacted to obstacles.

## Software & Technologies

- ROS 2
- TurtleBot3
- SLAM / Cartographer
- Navigation2 (Nav2)
- Gazebo
- RViz
- LiDAR
- Raspberry Pi
- OpenCR
- explore_lite

## Technical Areas

- ROS 2 configuration
- LiDAR integration
- Real-time mapping
- Autonomous navigation
- Dynamic obstacle avoidance
- Gazebo simulation
- RViz visualization
- Autonomous exploration
