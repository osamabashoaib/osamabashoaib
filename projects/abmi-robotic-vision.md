# 🤖 6-DoF Robotic Vision Demonstrator — ABMI Groupe

## Overview

This project focuses on the integration and validation of a **vision-guided 6-DoF robotic arm demonstrator**.

The public scope includes robotic integration, simulation, camera calibration, visual pose estimation, tracking and vision-guided manipulation.

## Software & Technologies

- ROS 2
- Python
- C++
- OpenCV
- Gazebo
- MoveIt 2
- URDF
- Linux
- ArUco / ChArUco
- solvePnP

## Technical Areas

- ROS 2 robotic-arm integration
- URDF modelling
- Controller integration
- Digital Twin in Gazebo
- Camera calibration
- Eye-to-hand / eye-in-hand configurations
- Pose estimation
- Tracking and filtering
- Vision-in-the-loop
- Pick-and-place
- Physical-system validation
