# ☀️ Automated Solar Tracking System

## Overview

An embedded mechatronics project that automatically adjusts the orientation of a photovoltaic panel according to the calculated position of the sun.

## Software & Technologies

- Arduino UNO
- Embedded C/C++
- RTC module
- Servomotors
- Solar elevation / azimuth calculation
- Mechanical design

## Technical Areas

- Solar elevation calculation
- Solar azimuth calculation
- RTC synchronization
- Servo control
- Automatic panel positioning
- Mechanical integration
