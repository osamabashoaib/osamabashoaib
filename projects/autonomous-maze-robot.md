# 🚗 Autonomous Maze Exploration Robot

## Overview

A custom differential-drive mobile robot developed for autonomous exploration of an indoor maze-like environment.

The robot combines camera vision, wheel odometry and distance sensors to follow walls, avoid obstacles, record movement and return toward its starting position.

## Software & Technologies

- Python
- OpenCV
- ArUco
- Raspberry Pi
- Arduino
- Serial communication
- Odometry
- Finite State Machine
- IR sensors
- Ultrasonic sensors

## Technical Areas

- Sensor acquisition
- ArUco marker detection
- Raspberry Pi ↔ Arduino communication
- Reactive obstacle avoidance
- Left-wall-following
- FSM-based behavior control
- Differential-drive motion
- Path recording
- Return-to-start logic
